# 拾光

瀏覽器本機中文照片語意搜尋。網站無上傳端點、無遠端推論 API。首次從 Hugging Face / jsDelivr 下載 Chinese-CLIP q8 模型及執行程式，圖片與查詢文字只在瀏覽器執行。

## 使用

選照片或資料夾 → 建立搜尋索引 → 輸入中文描述 → 調整相似度與結果數 → 選取 → 匯出原檔。

電腦支援 File System Access API 時可保存資料夾 handle 到 IndexedDB、重新授權連結、批次複製至新資料夾。其他環境使用檔案選取器和 ZIP。手機不能由網頁自動列出整個相簿，下次需重新選取照片。系統相簿選取器可能提供已轉換格式的檔案，匯出保留選取器提供的位元組。

IndexedDB 只保存 SHA-256 對應的特徵向量與可用的資料夾 handle；不保存照片 Blob 或縮圖。縮圖只在當次記憶體使用。原檔移動、變更或權限撤銷時需重新選取。瀏覽器清除網站資料會移除索引。裝置之間不會同步。

首次模型下載約 191 MB，WASM 單執行緒、Web Worker 序列分析。手機效能與記憶體仍需實機驗證，建議少量起步。ZIP 無壓縮，為降低記憶體風險單批限制 350 MB；電腦資料夾匯出逐檔寫入，不覆寫既有照片。

## 開發與驗證

靜態網站檔案在檔案庫根目錄；使用 HTTPS 或 localhost。語法檢查：`node --check app.js` 和 `node --check ai-worker.js`。

已用公開 Pikachu 與 football 測試圖片完成瀏覽器載入、q8 本機推論、繁體中文搜尋驗證：「足球場上踢足球的人」排序 football 0.412 > Pikachu 0.301。相似度不是正確率，不能保證所有相關照片都找到。
