# 拾光

線上網站：https://yayapewn.github.io/photo-finder/ 。GitHub Pages 自動發布 main 分支根目錄。

## 自動分類與命名

選資料夾後會自動分析全部圖片（包含子資料夾），再由網站判斷分類名稱，不需使用者輸入名稱或逐張勾選。按「建立分類資料夾並複製原檔」並選擇儲存位置後，建立一個新的「拾光分類-時間」總資料夾，內含有照片的分類。原檔留在原處，複製會占用額外磁碟空間。每張照片只歸入一類；同名檔案加上編號，避免覆寫。

目前依照 [百和官網產品介紹](https://www.paiho.com/tw/) 的 12 大類自動選擇名稱：射出勾、粘扣帶、數位梭織緹花布、四面彈、經編針織緹花網布、鬆緊帶、織帶、鞋帶｜拉繩、束頭、反光材料、保溫材料、紗線。名稱保留官網用字，鞋帶｜拉繩使用可作為檔名的全形分隔符號。

分類以本機 Chinese-CLIP 比對產品外觀描述，未使用百和圖片重新訓練，也未驗證百和產品辨識準確率。官網的應用領域（如鞋材、成衣）不當作產品類別。非產品照片、文件或成品展示設為排除候選；這些候選勝出、分數低或前兩類相近時放入「待確認」，無法分析的檔案保留在「未能分析」。每張照片都保留在輸出中。外觀相近的布料、織帶，以及彈性、材質、保溫性無法僅憑照片確認，匯出前請檢查分類預覽。

文字分類快取依百和版本與描述分開保存；更新分類不需重新分析既有照片。

支援資料夾寫入的電腦瀏覽器會直接複製原檔；其他瀏覽器可下載含分類資料夾的 ZIP（單批上限 350 MB）。

## 速度改善

重用相同照片的內容雜湊索引時，跳過 AI 與分析用解碼；分類文字特徵也保存在本機。首次使用仍需模型下載與逐張分析。預覽縮圖在瀏覽時可能仍需解碼。GPU 測試出現不正確排序，因此正式版本使用驗證過的 WASM 相容模式，沒有宣稱首次分析的固定加速倍數。

瀏覽器本機中文照片語意搜尋。網站無上傳端點、無遠端推論 API。首次從 Hugging Face / jsDelivr 下載 Chinese-CLIP q8 模型及執行程式，圖片與查詢文字只在瀏覽器執行。

## 使用

選照片或資料夾 → 自動分析與產品分類 → 預覽並另存分類資料夾。也可輸入中文描述搜尋並匯出結果。

電腦支援 File System Access API 時可保存資料夾 handle 到 IndexedDB、重新授權連結、批次複製至新資料夾。其他環境使用檔案選取器和 ZIP。手機不能由網頁自動列出整個相簿，下次需重新選取照片。系統相簿選取器可能提供已轉換格式的檔案，匯出保留選取器提供的位元組。

IndexedDB 只保存 SHA-256 對應的特徵向量與可用的資料夾 handle；不保存照片 Blob 或縮圖。縮圖只在當次記憶體使用。原檔移動、變更或權限撤銷時需重新選取。瀏覽器清除網站資料會移除索引。裝置之間不會同步。

首次模型下載約 191 MB，WASM 單執行緒、Web Worker 序列分析。手機效能與記憶體仍需實機驗證，建議少量起步。ZIP 無壓縮，為降低記憶體風險單批限制 350 MB；電腦資料夾匯出逐檔寫入，不覆寫既有照片。

## 開發與驗證

靜態網站檔案在檔案庫根目錄；使用 HTTPS 或 localhost。語法檢查：`node --check app.js` 和 `node --check ai-engine.js`。

已用公開 Pikachu 與 football 測試圖片完成瀏覽器載入、q8 本機推論、繁體中文搜尋驗證：「足球場上踢足球的人」排序 football 0.412 > Pikachu 0.301。相似度不是正確率，不能保證所有相關照片都找到。
